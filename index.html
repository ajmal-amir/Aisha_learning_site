How to add new content

You can keep using GitHub Pages and still add lessons anytime.

  1. Open content/sections.json in your GitHub repository.
  2. Copy an existing section block.
  3. Change the title, instructions, questions, and answers.
  4. Commit the change. GitHub Pages republishes the site.
Recommended upgrade later

If you want a friendlier admin panel instead of editing JSON manually, add a Git-based CMS such as Decap CMS later. That gives you a simple content editor while still keeping the site static.
